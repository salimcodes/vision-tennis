The question: can a model tell flat, slice and kick serves apart? Play the three clips and ask the room to name each. Answer: A = flat, B = kick, C = slice. Why it matters: the serve starts every point, and knowing which serve a player picks (on break point, out wide) is scouting. Today that tagging is done by hand.
02 · Prediction

Shot type: easy.
Serve type: hard.

trained models > frontier models
What we expected, before running it: (1) Every model should tell a serve from a volley from a groundstroke, because the whole-body motion is very different. (2) Serve type should be hard, because flat, slice and kick differ mainly in racket angle and spin in a split second, and THETIS has no ball, so the spin is invisible. (3) Models trained on THETIS—including Pose CNN and X3D—should beat frontier models used zero-shot, while pose may be especially strong on body-defined motion and weak where racket or ball cues matter.

Dataset · THETIS — Gourgari, S., Goudelis, G., Karpouzis, K., & Kollias, S. (2013). Thetis: Three-dimensional tennis shots a human action dataset. In Proceedings of the IEEE Conference on Computer Vision and Pattern Recognition Workshops (pp. 676–681).
Data: THETIS has 12 stroke classes recorded with Kinect and no visible ball. Shared 60-clip set: Claude Opus 5.5, ChatGPT GPT-6, Gemini Hydrogen and Pose CNN classify the same five clips per class. Pose CNN is a one-dimensional CNN trained on pose sequences extracted with MediaPipe Holistic. X3D condition: X3D RGB uses 396 held-out clips. X3D Skeleton 3D uses 250. Measures: exact class accuracy and broad category accuracy across groundstroke, volley, serve and overhead.

Small shared-set sample: Pose CNN and each frontier model use five clips per class, so one clip changes class recall by 20 points. Different test sets: X3D RGB uses 396 clips and X3D Skeleton 3D uses 250; direct ranking across those evaluations is not controlled. The comparison supports pattern analysis more strongly than precise ranking. Missing cue: THETIS contains no visible ball, so spin, trajectory and bounce are unavailable. Single run: the frontier evaluation uses one prompt and one run per model.
What the results support

Body motion finds the shot family.

What to test next

Ball flight is the next test for serve types.

Supported conclusion: every model performs better on broad category than on exact subtype. Pose CNN's 90% broad accuracy and recovery of seven shared frontier failures strengthen the evidence that body motion is sufficient for the shot family. Serve subtypes remain the most consistent shared confusion. Hypothesis: the missing ball removes cues that distinguish flat, kick and slice serves. Next experiment: use synthetic or captured clips with visible ball flight and controlled spin, then compare the same models with and without the ball cue.

Proof of concept: we extracted MediaPipe Holistic 3D landmarks from difficult THETIS serves and replayed the motion in Unity. The left clip shows Player 19, whose flat, kick and slice serves the Pose CNN misclassified. The right shows Player 36, whose three serves it classified correctly. Each sequence appears from the front, side and a three-quarter overhead view. What this establishes: we can carry real THETIS motion into a controllable 3D environment and inspect the same serve from viewpoints the original dataset does not provide. Current limit: time constraints prevented us from generating enough Unity data to retrain the models or measure improvement. Next phase: vary camera angle systematically, add controlled ball flight and spin, then export labeled sequences for training and targeted evaluation of the failure cases.
